# ozanalbayrak/homebrew-tap

Homebrew casks for [ozanalbayrak](https://github.com/ozanalbayrak)'s macOS apps.

```bash
brew install --cask ozanalbayrak/tap/fnswitcher
brew install --cask ozanalbayrak/tap/copystack
```

| Cask | App |
|---|---|
| `fnswitcher` | [FnSwitcher](https://github.com/ozanalbayrak/fn-key-mod-switcher) — toggle F1–F12 between function keys and media keys with a shortcut |
| `copystack` | [CopyStack](https://github.com/ozanalbayrak/copy-stack) — paste saved text snippets with global keyboard shortcuts |

Casks are bumped automatically by each app's release workflow.
